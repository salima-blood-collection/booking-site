# booking-site

Salima Blood Collection Website

A modern, responsive web platform designed to streamline blood donation requests, donor registration, and awareness for the Salima community.

📌 Features

Donor Registration & Portal: Easily sign up to become a blood donor with details like blood group, location, and contact information.

Urgent Blood Request: Quick form submission for urgent blood requirements with instant notifications/visibility.

Search Donors: Filter blood donors by blood group and location.

Interactive Information: Educational content about eligibility, benefits of blood donation, and frequently asked questions.

Responsive Design: Fully optimized for mobile, tablet, and desktop screens.

🛠️ Tech Stack

Frontend: HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)

Icons & Assets: FontAwesome / Lucide Icons

Deployment: GitHub Pages / Vercel / Netlify

🚀 Quick Start

Prerequisites

To run this project locally, you only need a modern web browser.

Installation & Local Setup

Clone the repository:

git clone https://github.com/your-username/salima-blood-collection.git


Navigate to the project directory:

cd salima-blood-collection


Open the application:

Double-click index.html to open it in your default browser, or

Use a live server extension (e.g., Live Server in VS Code) for local development.

📂 Project Structure

salima-blood-collection/
